# Increasing the challenge of shape correspondence tasks via a non connectivity-preserving remeshing


**Author:** Simone Pedico.  
**University:** University of Milano-Bicocca.

[Read the thesis](tosca_remesh_thesis.pdf)

<p align="center">
  ABSTRACT
</p>

*In real-world scenarios, having a dataset where all meshes of the same subject in different poses have the same connectivity can limit its representational power and applicability. Specifically, similar connectivities simplify the matching process, potentially leading to correspondences based on the recurring triangle patterns rather than correspondences between mesh parts. Consequently, the resulting matches are non-significant. To avoid this problem, we create and evaluate a new dataset where the connectivity varies from mesh to mesh, making the matching more challenging. We also calculate the correspondence between the meshes of the new dataset to demonstrate how much it impacts the final accuracy.*
