# Exploring the Impact of Introducing Geometric Information for Mesh Generation from Single View

**Author:** Simone Pedico.  
**University:** University of Milano-Bicocca.

[Read the thesis](mesh_generation_thesis.pdf)

<p align="center">
  Abstract
</p>


*Single-image mesh generation is a challenging task in computer graphics and robot vision, aiming to reconstruct a 3D mesh from a single image. The ambiguity inherent in the transformation from 2D to 3D often results in noisy outputs and geometric imperfections. With the development of increasingly accurate models for depth and normal estimation, it is possible to extract additional geometric information from a single image. In this thesis, we investigate whether incorporating such information into a 3D generation pipeline (by generating depth and normal maps from the input image) can improve the quality of the generated mesh. Specifically, we started from Human3Diffusion, an existing 3D generation pipeline for single-image 3D generation, and modified its architecture to accept a 7-channel input instead of the original 3-channel input, allowing depth and normal maps to be incorporated as additional geometric information. During inference, we generate depth and normal maps from the input image using Marigold, a map estimation model.  To enable the modified architecture to use this additional information, we fine-tuned the model on a custom dataset designed to provide RGB images with corresponding depth and normal maps. Since the maps generated by Marigold can differ from those used during training, we designed a post-processing step to make them consistent with the training data. We evaluated the performance of our pipeline and compared it with the performance of the original Human-3Diffusion model to assess the impact of the additional geometric information.*
